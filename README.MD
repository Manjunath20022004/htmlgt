# Personal Website Demo

A simple personal portfolio website built with HTML, CSS, and JavaScript. This project demonstrates a beginner-friendly landing page with a navigation bar, hero section, skills cards, and a contact form.

## Features

- Responsive personal website layout
- Navigation links for Home, About, Skills, and Contact
- Hero section with introduction and call-to-action button
- Skills section with HTML, CSS, and JavaScript cards
- Contact form with JavaScript form handling
- Simple interactive behavior using JavaScript

## Project Structure

```text
htmlgt/
├── demo/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── README.MD
└── .gitignore (if added later)
```

## Files

- `demo/index.html` — page structure and content
- `demo/style.css` — styling and layout design
- `demo/script.js` — small interactive JavaScript functions

## How to Run

1. Open the project folder in your browser.
2. Navigate to the `demo` folder.
3. Open `index.html` in a browser.

You can also use a local development server if you prefer, for example:

```bash
cd demo
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Demo Behavior

- Clicking the "Say Hello" button displays a greeting alert.
- Submitting the contact form shows a thank-you message and resets the form.
